# Vayana 0.92

A reading, search, widget and sync update since [v0.90](https://github.com/rjwarrier/Vayana/releases/tag/v0.90).

## Highlights

- **Calmer, more accurate reader:** Distraction-free reading comes first, with a setting to keep page indicators on screen. Tap the page number to jump to a page; page totals are measured for your current layout and marked while still estimates. Text alignment has four icon choices, read aloud stays on the toolbar when audio is on, and read aloud now speaks exponents, powers and fractions correctly.
- **Finishing a book:** Save an optional reflection with the completion and rating, kept as a normal reading-journal note.
- **Better search:** Quote a phrase (`"like this"`) to match it exactly across book details, notes and highlights, and downloaded EPUB text, and scope phrase and prefix results by book or shelf. In-book EPUB search results now show plain readable excerpts, keep the whole phrase when it spans italic or bold text, and never leave stale highlights behind.
- **Cleaner EPUBs:** Cleanup repairs unambiguous prose artifacts and Project Gutenberg missing-illustration codes, and recovers reading positions with progress shown.
- **Physical books and stats:** Stats lists reading records with covers, dates and recorded time, including physical books in progress. A book added at its final page gets a finish date, so it counts towards the yearly goal. A manual reading log now updates the current page when it is the latest reading or goes past the current page. The physical reading timer ticks once a minute on E-Ink.
- **Widgets:** Responsive Continue reading layouts with an optional border; the reading-time widget gains graph types, axis labels, grid strength, day range, header and fill options. Both widgets share one theme palette, and the configure screen is grouped by what each option changes.
- **Much faster sync:** Unchanged data is no longer re-exported or re-uploaded, and a publish is a single GitHub commit. A full sync with nothing new dropped from minutes to about a second on a large library. Goodreads quotes sync in their own slice, and snapshots record the app build that published them.
- **Safer sync and backup:** Sync stops instead of treating a missing or oversized cloud slice as empty data; failed downloads no longer crash or publish partial merges. Backups capture a consistent database snapshot, including recent write-ahead-log changes. Sync merges work on Android 8–10 again.
- **Security:** Scripts embedded in EPUB resources can no longer reach reader controls, and malformed reader bridge events are ignored.
- **E-Ink and display:** Colour E-Ink screens use Material 3 tonal (wallpaper) colours; monochrome E-Ink keeps the ink-on-paper look. Dates follow your regional preferences everywhere.
- **Performance:** Smaller, compressed EPUB search index; notebook exports regenerate only what changed; faster global search; a 180 ms main-thread startup cost removed.

The database upgrades automatically (schema v34 to v37) on first launch.

## Downloads and installation

- **Phone/tablet:** Install `Vayana-v0.92.apk` on Android 8.0 (API 26) or newer. It uses the same release certificate as v0.90, allowing an in-place update.
- **Wear OS:** Install `Vayana-WearOS-v0.92.apk` on a Wear OS 3+ (API 30+) watch with Google Play services and a paired Android phone, together with the 0.92 phone app. Install the watch APK on the watch, not on the phone.
- **Version:** Both APKs use version name `0.92` and version code `4`.
- **Build:** Both are signed release APKs with code minification and resource shrinking disabled. Each download has a `.sha256` checksum file.

## Validation

Release signatures, packaged versions and matching phone/watch certificates are checked before publication. Android unit tests and the reader-engine suite pass. Automated checks do not verify real paired-device delivery, watch layout or reminder timing.
